# /pwx — conectar, olhar, agir, cristalizar, fechar

`pwx` comanda um navegador real e logado: cada papel (conta) é um Edge **invisível** (headless: nunca rouba o foco); cada sessão do Claude ganha nele a própria janela, que fecha quando o Claude termina (`/exit`, terminal fechado, crash), e o Edge fecha sozinho quando fica sem sessão e sem aba do usuário. Logins no perfil.

1. **Garantir — a máquina está configurada.** Configurada = `pwx --help` responde, `pwx`/`browser`/`pwx-background.cjs` em `~/.local/bin` iguais aos de `scripts/` (fora o shebang) e `~/.claude/settings.json` com os hooks `SessionStart` (aviso + `pwx gc`) e `SessionEnd` (`close-tab`). Faltou algum (máquina nova, skill atualizada, Node trocado, `env: node: No such file`) → rode `scripts/install.sh` desta skill (idempotente; Node ≥ 20 e um Chromium, cujo caminho vai como argumento se não achar) e repita. Ele deixa `pwx`/`browser` com o node absoluto no shebang (rodam sem nvm, como no hook) e os hooks. Janela só a pedido do usuário, nunca por conta própria: login que só ele faz (primeiro uso do papel, 2FA, SSO, conta pessoal) → peça e, com o sim, `browser show <papel> <url>`; terminou → `browser hide <papel>` (só a abertura vem à frente; minimizada, a página pausa). `pwx` diz que o navegador não respondeu → `browser up [papel]`; OAuth da Microsoft abre aba nova que cai no login do app (o Edge desviou para outro perfil do papel) → o papel subiu antes desta versão: `browser down <papel>` e `browser up <papel>`; papel inexistente → `browser add <papel>` e o mesmo pedido de login.
2. **Olhar — só quando precisa.** `pwx goto <url>`, depois `pwx snapshot` para ler a página e pegar as refs (`e12`). Snapshot custa tokens: tire um por tela nova, não um por ação; `pwx find "<texto>"` acha um trecho sem ler tudo.
3. **Agir — pela ref ou pelo seletor.** `pwx click e12`, `pwx fill e5 "texto"`, `pwx press Enter`, `pwx eval '() => location.href'`, `pwx screenshot --filename=<arquivo>`. Outra página → `pwx goto <url>`; link de nova aba e popup abrem na mesma aba. Outra conta → o papel na frente: `pwx admin goto …`; papel novo só para um login que nenhum papel tem (cada papel é mais um Edge). Duas janelas no mesmo projeto → `PWX_SESSION=<nome> pwx …`; janela entre Claudes (orquestrador) → `PWX_OWNER_PID=<pid>` (vive com ele) ou `0` (até o `PWX_SESSION=<nome> pwx close-tab`). Marcar o ponto num print → `pwx mark <ref> "BUG"`, `screenshot`, `mark --hide`. `pwx --help <comando>` dá as opções.
4. **Cristalizar — o que se repete vira script.** Fluxo que funcionou e vai se repetir → escreva um script Playwright que conecta no mesmo navegador (`chromium.connectOverCDP(process.env.PWX_CDP)`), abre a própria página com `browser.contexts()[0].newPage()` e a fecha no fim — nunca `browser.close()` num navegador compartilhado. Rode com `pwx [papel] run <script> [args]`: sobe o navegador do papel e entrega o `PWX_CDP`.
5. **Fechar — a aba é sua, o resto não.** Terminou → `pwx close-tab` (fecha as janelas da sessão em todos os papéis). Nunca feche aba de outra sessão, nunca faça logout nem troque conta no perfil compartilhado (derruba todas as sessões daquele papel), nunca derrube o navegador (`browser down`) sem o usuário pedir.

**Credenciais — `.secrets/` do projeto, à disposição.** Login de conta de teste → pegue em `.secrets/test-accounts.md` e digite (`pwx fill`). Nenhuma serve e o app permite cadastro em local ou homolog → crie uma reutilizável e registre lá (ambiente · papel · login · senha · para quê · criada em), para a próxima sessão não criar outra. Todo segredo que aparecer (token colado, senha nova, chave girada) → atualize em `.secrets/` na hora (`.secrets/<provedor>.env`; `.secrets/` no `.gitignore`); o valor nunca vai para chat, script ou screenshot. Conta pessoal do usuário, 2FA ou SSO → peça que ele entre (`browser show`, passo 1).
